## 1. Project Overview

**Space Exploration Idle PWA** — a Progressive Web App built with React 18,
TypeScript, and Vite. Phase 1 foundation includes a PWA shell (standalone
display mode, Web App Manifest, service worker via `vite-plugin-pwa`),
client-side game engine (`src/engine/`), and a full testing pyramid
(unit + component + E2E).

**Critical context for iOS**: iOS Safari does NOT support the standard
`beforeinstallprompt` event. PWAs installed to the Home Screen bypass
iOS Safari's 7-day Intelligent Tracking Prevention (ITP) local-storage
wipe, ensuring game state persists. A custom install prompt is required.

## 4. Testing Conventions

### Vitest + jsdom + @testing-library/react v14

- **Globals**: `describe`, `it`, `expect`, `vi`, `beforeEach`, `afterEach`,
  `beforeAll`, `afterAll` are available globally (`globals: true` in config).
- **Setup file**: `vitest.setup.ts` runs before all tests. It:
  - Imports `@testing-library/jest-dom` (custom matchers like
    `toBeInTheDocument()`).
  - Mocks `window.matchMedia` to return `{ matches: false, ... }` by default.
- **Test file naming**: `*.test.ts` (logic) and `*.test.tsx` (components),
  placed in `src/` alongside the source file.
- **Test isolation**: Each test file runs in its own jsdom environment
  (Vitest default), so window/navigator modifications don't leak across files.

### Mocking Patterns

```ts
// Mock navigator properties
Object.defineProperty(navigator, 'serviceWorker', {
  value: { controller: null, addEventListener: vi.fn(), ... },
  configurable: true, writable: true,
});

// Mock window.matchMedia (replaces the global setup mock)
Object.defineProperty(window, 'matchMedia', {
  writable: true,
  value: vi.fn().mockImplementation((query) => ({
    matches: false, media: query, ...
  })),
});

// Mock navigator.userAgent / navigator.standalone
Object.defineProperty(navigator, 'userAgent', { value: '...', configurable: true });
Object.defineProperty(navigator, 'standalone', { value: undefined, configurable: true, writable: true });
```

### React Testing Patterns

- Use `act()` for rendering components with effects.
- For async state updates, use `waitFor()` or `findByTestId()`.
- For negative assertions, use `queryByTestId()` with `waitFor()`.
- `renderHook` and `act` are available from `@testing-library/react` v14.3.1
  for testing hooks directly.
- `fireEvent.click()` is automatically wrapped in `act()`.

## 6. Feature: iOS "Add to Home Screen" Install Banner

### Problem

iOS Safari does NOT support the standard `beforeinstallprompt` event.
Without a manual prompt, iOS users who browse in standard Safari mode are
subject to Apple's 7-day Intelligent Tracking Prevention (ITP) local-storage
wipe, which can delete their save-game progress.

### Solution

A React hook + component that:

1. Detects iOS devices via `navigator.userAgent` (iPhone, iPad, iPod).
2. Checks if the PWA is already in standalone mode via two methods:
   - `navigator.standalone` (legacy, iOS Safari only).
   - `window.matchMedia('(display-mode: standalone)')` (modern spec).
3. Checks `sessionStorage` for a dismissal flag (session-only).
4. Shows a banner with an inline SVG and instructions only when the user
   is on iOS, NOT in standalone mode, and HAS NOT dismissed in this session.

### Gotchas & Reminders

1. **`navigator.standalone`** is NOT in standard DOM lib. Use type assertion.
2. **`sessionStorage` vs `localStorage`**: The prompt mentions "localStorage"
   but the user chose session-only behavior. `sessionStorage` is the correct
   Web Storage API for session-only semantics.
3. **`vitest.setup.ts`** already mocks `window.matchMedia`. Save/restore
   the original in `beforeEach`/`afterEach` to avoid leaking mocks.
4. **`renderHook`** is in `@testing-library/react` v14.3.1 (NOT
   `@testing-library/react-hooks`).
5. The existing `App.test.tsx` tests are unaffected because jsdom's
   default `navigator.userAgent` is non-iOS.
6. Use forward slashes in `editor` tool paths on this Windows environment.
7. Omit `.ts`/`.tsx` extensions in imports — Vite + `allowImportingTsExtensions`
   resolves them.
